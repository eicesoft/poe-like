# 魂火远征 · EXILE OF EMBERS

> 类《流放之路（Path of Exile）》的 **2.5D 刷宝动作 RPG 网页原型**。
> 纯前端（原生 ES + Canvas2D 伪 3D 渲染），无外部素材、无需联网。

## 快速开始

| 方式 | 操作 |
| --- | --- |
| **单文件版（推荐给直接体验）** | 双击 **`index-standalone.html`** —— 所有代码/样式内联，浏览器直接运行 |
| 开发版（原生 ESM） | `npm run dev` → 打开 `http://127.0.0.1:5178/`（或任意静态服务器） |
| 重新打包单文件 | `npm run build`（自研轻量 ESM 打包器，输出 `index-standalone.html` 与 `dist/game.js`） |
| 测试 | `npm test` → `node tests/run-all.mjs`（465 项） |
| 平衡/压力跑测 | `node tools/playtest.mjs --minutes 10 --seed 42 --bot skilled` |
| 单文件冒烟验证 | `node tools/check-standalone.mjs` |

## 操作（方向键移动 · QWERT 技能）

> 键位的**唯一真相**是 `src/game/input.js` 的 `SKILL_KEYS`：HUD 技能栏角标、读键逻辑、测试全部读它。
> 技能栏第 i 格 ↔ 第 i 个键（Q/W/E/R/T），改键位只需要改这一张表（`tests/input-chain.test.mjs` 会守着两边一致）。

| 按键 | 说明 |
| --- | --- |
| **↑ ↓ ← →** | **移动**（主操作；A/S/D 也能移动，见下方「W 为什么是技能」） |
| **Q** | 1 号技能：战争践踏（范围眩晕 + 按命中数给自己加护甲） |
| **W** | 2 号技能：旋风斩（按住持续旋转） |
| **E** | 3 号技能：战吼 |
| **R** | 4 号技能：血性狂暴 |
| **T** | 5 号技能：坚毅图腾 |
| **鼠标左键** | 普通攻击（按住连续攻击，始终朝鼠标方向） |
| **鼠标右键** | 持续施放 2 号技能（旋风斩） |
| **空格** | 翻滚（0.18 秒无敌） |
| **1 ~ 5** | 数字键是 Q~T 的别名，仍然可用 |
| **F** | 互动 / 拾取：在庇护所靠近仓库、商人、赌徒打开对应面板，靠近战斗之门开启战斗地图；战斗地图上仍是手动补拾脚下装备（普通/魔法/稀有/传奇靠近后都会自动拾取；掉落 120 秒后消失） |
| **I** | 背包与装备（**左键穿戴 · 右键出售**；橙色装备出售前会二次确认；悬停物品会与当前装备对比战力/属性） |
| **C** | 属性面板（角色数值一览 + 基础/装备/天赋/增益的来源拆解） |
| **P** | 天赋树（缩放拖拽，点击加点） |
| **K / Tab** | 技能天赋面板（每个技能一个标签页：加点、精炼、重置天赋、左右分叉） |
| **M** | 静音 / 取消静音 |
| **Esc** | 暂停 / 继续（有面板打开时先关面板）；暂停中可打开任意面板 |

**W 为什么是技能？** 方向键已经完全承担移动（`↑ ↓ ← →`），所以 W/A/S/D 里的 **W 让给了 2 号技能旋风斩**，
A/S/D 仍然可以移动。不用担心把原 WASD 习惯弄坏：
- 若某格技能被清空（例如 2 号格子空了），**W 会自动退回「向上移动」**，不需要改代码（见 `isMoveKey` / `playerMoveDir`）；
- 老的数字键 1~5、鼠标左右键、空格翻滚、点技能格按钮**全部照旧可用**。

> **法师按键不同**：Q/W/E/R 是火/冰/雷/炎爆（由自动循环代放，也可手动按），**左键改成锁定目标**，空格是**闪现**，**T** 在共鸣满 100 时开启元素狂潮。开始界面点选职业卡即可选择战士或法师（也可按 `←/→` 或 `1/2`）；开始按钮会显示「以元素法师进入神庙」等当前选择。

老快捷键的去向（不会冲突）：

| 老键位 | 现在 | 替代 |
| --- | --- | --- |
| E 背包 | E = 3 号技能（该格空着时才退回背包） | **I** 背包 |
| R 拾取 | R = 4 号技能（该格空着时才退回拾取） | **F** 拾取 / 普通·魔法自动拾取 |
| T 回城下一层 | T = 5 号技能（该格空着时才退回回城） | 点技能栏最右侧的 **🏕** 格子（在家中进入战斗地图，在战斗中回庇护所） |

### 底部面板按钮

左下角常驻一排 4 个带图标的按钮，**点一下打开对应面板，再点一下关闭**；当前面板会高亮：

| 按钮 | 快捷键 | 打开的面板 |
| --- | --- | --- |
| 👤 属性 | C | 属性面板：概要 / 攻击 / 防御 / 抗性 / 资源 / 已装备，点任意属性行展开来源拆解 |
| ✦ 天赋 | P | 天赋树（战士 / 法师各 70 节点，按职业自动切换） |
| ✧ 技能 | K / Tab | 技能天赋分叉（加点 / 精炼 / 重置） |
| ⬢ 装备 | E / I | 背包与 10 个装备槽 |

> 面板按钮的键位说明里 E 仍作备选：**E 现在是 3 号技能**，只有在 3 号格子被清空时才会退回「打开背包」。日常请用 **I** 开背包。

### ESC 暂停

按 **ESC** 冻结整个世界（怪物、技能冷却、持续伤害、掉落吸附、粒子全部停住；画面轻微去饱和）并弹出暂停菜单：

- **继续游戏** / **属性** / **天赋** / **技能** / **装备** / **音效开关** / **保存游戏** / **返回主菜单**（需二次确认）
- 暂停中打开面板不会解除暂停；关掉面板会回到暂停菜单，再按一次 ESC 才继续
- 键盘可全程操作：`↑ ↓ ← →` / `Tab` 切换按钮，`Enter` / `空格` 确认，`ESC` 返回
- 底部按钮列在暂停时仍然可点，方便暂停中直接查看属性、天赋与装备

> 存档：开始界面有存档时按钮显示「继续旅程」并展示摘要；游戏中每 60 秒、换图、升级时自动存档，暂停菜单里也可以手动保存。

## 玩法循环

0. **庇护所（家）**：进入游戏先落在 tier 0 的安全大厅——没有怪物、没有地图词缀。四个交互点：
   **仓库**（背包 ↔ 60 格仓库，存档持久化）、**商人**（8 件随等级刷新的装备，可买可卖）、
   **赌徒**（付金币赌装备：45% 空手 / 33% 魔法 / 16% 稀有 / 6% 传奇）、**战斗之门**（地面光圈，按 F 开启战斗地图）。
   靠近设施按 **F** 互动；站在光圈里按 **F**，或点技能栏 **🏕**，前往战斗地图。
   新游戏、继续游戏与读档都**先进入庇护所**；存档的历史层数会保留为战斗之门的目标层，不会丢失进度。
1. **刷图**：每层都是全新随机地牢（房间式 / 方格神殿 / 洞窟三种布局 × 五套主题），带随机地图词缀（怪物强化或掉落提升）。
2. **清怪**：小怪从暗处持续涌出；每 12 波一次精英波，每 12 波（约 4 分钟）降临首领「深渊主宰」。
3. **掉落**：击杀 → 魂火（金币/经验/生命/法力，自动吸附拾取）→ 装备（靠近自动拾取，普通/魔法/稀有/传奇都收）。
4. **整备与深入**：随时点 **🏕** 回庇护所（自动收走地上掉落、回满血蓝），在仓库整理装备、找商人补货或去赌徒搏一把；
   再次穿过战斗之门会从**更深一层**开始。死亡后也在庇护所复活，可重打当前层。
5. **成长**：升级拿天赋点 + 技能点；自动换上更强的**普通/魔法**装备（稀有/传奇留在背包里，由你自己比较后决定；背包里左键装备、右键出售，橙色出售需确认）；把更强的装备与天赋推向下层更难的图。

## 系统一览

- **战士职业**：生命 120 / 法力 60 起步，近战爆发 + 生存。初始技能：**战争践踏**（以自身为圆心的范围践踏，眩晕敌人；命中的敌人越多，自身的「踏地战甲」护甲越高，持续数秒）、旋风斩（持续旋转 AOE）、战吼（群体恐吓 + 增伤）、血性狂暴（攻速/暴击增益）、坚毅图腾（范围回蓝）。
- **元素法师职业**：生命 88 / 法力 100 起步，火/冰/雷半自动循环。自动释放灼热飞弹、寒冰箭、电弧与炎爆术，命中叠印记并触发元素反应；共鸣满 100 后手动开启 **8 秒元素狂潮**。玩家只负责走位、左键锁定和放大招的时机，详见下方专节。
- **装备**：10 个槽位（武器/副手/头盔/护甲/手套/腰带/双戒指/项链/靴子）。
  - 70 个基底（4 阶武器 17 把，含 4 把法师法杖 / 魔杖、5 件法师护甲）、**125 条词缀**（57 前缀 + 68 后缀，每条 2-7 档，按组互斥）、**23 件暗金**（每个部位至少 2 件，其中 12 件为法师专属，带独特效果）。
  - 掉落：高阶基底（T3/T4）与稀有 / 暗金概率随地图深度提高；精英额外掷暗金，Boss 必掉 1 件暗金（35% 再掉一件）。
  - 属性：生命/护甲/闪避/格挡/武器伤害/攻速/暴击/暴伤/移动/元素伤害与抗性/范围/偷取/冷却缩减/掉宝率等 43 项。
- **天赋树**：两个职业**各 70 个节点**，按职业自动切换，BFS 验证全连通。
  - 战士：6 条主干 × 10 节点（6 基石）+ 6 个内环接缝 + 3 传奇 + 1 起点。
  - 法师：4 条元素主干 × 14 节点（4 基石）+ 4 内环 + 4 外环接缝 + 5 传奇 + 1 起点。
  - 两边都有 9 个「基石 + 传奇」大节点、8+ 个显著节点，构筑深度与点数预算对齐。
- **技能树 + 技能等级 + 分叉天赋**：**10 棵**技能树（战士 5 + 法师 5，每棵 9~12 节点，左右互斥双支 + 终极节点），每个技能另有 1~5 级技能等级（天赋点 + 技能精炼石叠加），详见下一节。
- **庇护所（家）**：tier 0 安全大厅，仓库 60 格 / 商人 8 件随等级刷新 / 赌徒 / 战斗之门光圈；不刷怪、不掷地图词缀，是所有补给与整备的枢纽。
- **随机地图**：两种地牢生成算法 + 保底大厅；13 种地图词缀。
- **怪物**：7 种（枯萎尸/毒蛛/骸骨弓手/地狱犬/重装屠夫/幽魂/自爆尸）+ 精英词缀 + 首领技能（重击 AOE、地面熔岩）。
- **战斗公式**：闪避 → 护甲（POE 式 `armor/(armor+10×伤害)`，上限 75%）→ 元素抗性 → 暴击 → 生命偷取/击中回复。

## 元素法师（半自动循环）

开始界面有两张职业卡：**战士**（原有全手动近战）与 **元素法师**。选择后开始游戏；存档会记录职业，
开始界面自动选中存档职业，旧存档没有职业字段时按战士读取。法师不需要改键位表：

| 按键 | 法师行为 |
| --- | --- |
| **Q / W / E** | 灼热飞弹（火）/ 寒冰箭（冰）/ 电弧（雷）——循环会自动释放，按下只是手动补一发 |
| **R** | 炎爆术：目标周围半径 3 的火焰 AOE；目标带 3 层火印记时强化 |
| **T** | 元素狂潮：**共鸣满 100** 才能开启，8 秒爆发窗口 |
| **鼠标左键** | 锁定 / 解锁目标（点到敌人锁定，点空地解除） |
| **空格** | 闪现（沿用原 dash 机制，0.18 秒无敌） |
| **1 ~ 5** | 与 Q~T 等价的技能别名 |

### 自动循环怎么工作

- 每 **0.1 秒**评估一次优先级，两次施法之间至少隔 **0.75 秒**；角色移动、施法互不打断。
- 优先级：**低血冰霜屏障** → **身边≥2 敌人放霜环** → **3 层火强化炎爆** → **雷链（目标 2 层雷且周围≥2 敌人）** → **多目标炎爆** → **填充技轮转**。
- 三个填充技按预设选元素：
  - **均衡**：火 → 冰 → 雷轮转，先铺不同印记；
  - **反应流**：优先选择能与目标现有印记触发反应的元素；
  - **蓄积流**：先把同系印记叠到 3 层，再交给强化循环技。
- HUD 会显示「自动目标 / 锁定目标」、下一手技能高亮、共鸣条与大招就绪状态；技能栏上方可随时切换预设。

### 印记与元素反应

每次元素命中给目标叠 **1 层对应印记（最多 3 层）**。若目标身上已有其它元素印记，则消耗 1 层并触发反应
（**每个目标 2.5 秒内置冷却**，防止高频刷屏）：

| 组合 | 反应 | 效果 |
| --- | --- | --- |
| 火 + 冰 | **熔解** | 额外火焰伤害 |
| 火 + 雷 | **超载** | 目标周围 2.6 范围火焰爆炸 |
| 冰 + 雷 | **等离子** | 雷电伤害 + 0.8 秒眩晕 |

每次反应获得 **+15 共鸣**。把单一印记叠到 3 层再放对应强化技，额外获得 **+25 共鸣**：

- **炎爆术**：3 层火 → 1.9 倍伤害、半径扩大、眩晕 1 秒；
- **霜环**（自动，身边≥2 敌人）：3 层冰 → 1.45 倍伤害与半径、眩晕更长；
- **雷链**（自动，目标 2 层雷且周围≥2 敌人）：3 层雷 → 跳跃 5 次而非 3 次。

### 元素狂潮（T）

共鸣 100 时按 T：清空共鸣，进入 **8 秒**强化状态——技能冷却减半、法力免费、每次施法附带一次小范围爆炸；
结束时以自身为圆心造成一次大范围爆发。施放后 T 进入 9 秒冷却，期间无法重复开启。

### 成长与限制

- 法师有**专属的 70 节点天赋树**（P 键）：烈焰 / 霜寒 / 雷霆 / 共鸣四条主干（每支 14 节点），
  主干之间的 8 个环形接缝可以横向换元素；内圈 5 个传奇：环形法球、三相归一、元素回响、共鸣核心、霜火壁垒。
- 天赋不只加数值，还会解锁**看得见的新战斗机制**：
  - **天火陨星**：周期性从天空砸下陨星（火柱 + 落地裂纹 + 震屏）；
  - **环绕法球**：火 / 冰 / 雷三色法球绕身旋转，自动向敌人发射弹道；
  - **三相归一**：每 3 次填充施法，火 / 冰 / 雷三道弹道同帧齐射；
  - **元素回响**：元素反应会向周围敌人弹射同色电光；
  - **三相共鸣**：印记上限 3 → 4，怪物头顶的印记菱形会多一颗。
- 法师的 5 个技能也各有**左右互斥的分叉技能树**（K / Tab 打开），与被动天赋树完全独立：
  灼热飞弹（爆燃 / 流火）、寒冰箭（碎冰 / 寒流）、电弧（连锁 / 过载）、
  炎爆术（陨火 / 熔核）、元素狂潮（万相 / 永动）。分支会解锁余烬爆炸、凤凰之焰、
  冰爆冻结、分裂冰片、跳弧、雷暴、流星雨、熔岩池、天火焚世、元素奇点等机制。
- 法师的自动技能（霜环 / 雷链 / 冰霜屏障）不占技能栏，因此不会出现「技能栏里多出格子」的键位问题。

## 技能升级与分叉天赋

每个技能都有**等级**和**左右互斥的分叉天赋树**。按 **K / Tab** 打开技能面板，每个技能一个标签页。

### 技能等级（1 → 5）

- **技能等级 = 1 + 该技能已投入的天赋节点数 + 精炼等级**（精炼 0~4），上限 **5**；两条路叠加、互相放大。
- **天赋点**：每升 1 级获得 **1 点技能点**（全局共享池，曲线 = 等级：Lv.1 = 1、Lv.10 = 10），点分叉天赋树节点。
- **天赋树点数**：另有一棵全局天赋树（P 键），每升 1 级获得 **2 点**天赋点。
- **技能精炼石**：另一种升级货币，给某个技能「精炼 +1」，直接加技能等级。
- 等级收益：伤害倍率、冷却缩减、范围，以及各技能的关键机制数值（践踏：眩晕时长 + 每命中一名敌人的护甲）。

### 左右互斥的分叉路线

```
          ┌─ L1 ── L2 ── L3 ── L4（分支专精）
 ROOT ───┤                            互斥：只能走一支
          └─ R1 ── R2 ── R3 ── R4（分支专精）
                              └─ U（终极，两处前置）
```

- 每层的左/右节点**互斥**：点了左边，右边那一层的节点就会锁死并提示原因。
- 两支方向不同，例如战争践踏：**左支「震怒」**（伤害 / 范围 / 余震），**右支「壁垒」**（护甲 / 眩晕时长 / 控制）。
- 想换路线：在技能面板点 **重置天赋**，用精炼石重置该技能树（花费 = 2 + 已点节点数），技能点会退回。

### 技能精炼石的来源

- **击杀掉落**（自动吸附拾取，1.6 半径内入包）：普通怪 6%、魔法怪 12%、**稀有 35%、Boss 100%（一次给 3 颗）**。
- 所以刷精英/Boss 是攒石头的正道；10 分钟无头跑测里机器人通常能拿到 **20~30 颗**。

### 功能提醒（怎么知道自己能升级了）

| 提醒 | 触发条件 |
| --- | --- |
| 技能栏**光点角标** | 有可用技能点，或某个技能当前可以精炼时，对应技能图标上出现光点 |
| **横幅 + 音效 + 光点** | 加点成功（`skillRankUp`）、精炼成功（`skillRefine`）、重置天赋（`skillRespec`）、拾到精炼石（`skillOrbGain`） |
| **HUD 悬浮提示** | 技能栏上方提示「有 N 点技能点可分配 / M 个技能可精炼（点此或按 K/Tab 打开）」 |
| **新手引导** | 首次打开技能面板时显示一条引导（说明加点 / 精炼 / 重置按钮） |
| **事件日志** | 上述事件都会带图标写一行日志 |

### 机器人是怎么消费的（`tools/playtest.mjs`）

- **技能点**：全局排序后投给「主输出技能」的伤害/范围/护甲/眩晕节点（战争践踏优先）；互斥组的另一个节点直接跳过，`doSkillRankUp` 返回 false 的节点记进 rejected 集合，**不会死循环**。
- **精炼石**：优先精炼伤害占比最高的技能（战争践踏 / 旋风斩），**始终预留 2 颗**用于改派分叉；主技能到高级要 6~8 颗时，退而精炼付得起的其它技能，不让石头躺尸。
- **分叉冲突**：技能点还剩、但所有可点节点都被互斥锁死时，用 `doSkillRespec` 花石头重置后改派（每个技能 3 分钟最多一次）。
- 报告里会输出：`技能等级`、`分叉选择`、`技能精炼石：获得 N 颗，已用 M 颗`、`战争践踏 / 踏地战甲` 覆盖率。

### 报告里新增的三行（`node tools/playtest.mjs`）

跑测报告的「成长」段会多出这三行（外加「战斗」段的两行践踏统计）：

```text
── 成长 ──────────────────────────────────────────────────────────
 技能等级：战争践踏 Lv.5 / 旋风斩 Lv.5 / 战吼 Lv.5 / 血性狂暴 Lv.5 / 坚毅图腾 Lv.5
 分叉选择：战争践踏 左支 / 旋风斩 未分叉 / 战吼 未分叉 / 血性狂暴 未分叉 / 坚毅图腾 未分叉
 技能精炼石：获得 26 颗，已用 23 颗（精炼 23 / 重置 0），手里 3 颗（预留 2 颗）   成功精炼 7 次   重置天赋 0 次

── 战斗 ──────────────────────────────────────────────────────────
 战争践踏   释放 92 次 / 命中 115 次（平均 1.25 个目标）   眩晕 28 次（累计 45.7s）结束 5 次
 踏地战甲   覆盖率 69.7%   最近一层护甲 +23（剩 3.3s）   单次最高 +58
```

- **技能等级**：天赋投入节点数 + 精炼等级 + 1（上限 5），与游戏内 `skillLevelOf` 同口径（core 的 `skillsUpgrade` 与面板/`skillProgression` 都按「节点数」计天赋点）。
- **分叉选择**：读 `player.skillMods[id].focus`（data-dev 写入），缺失时退回 `player.skills[id].focus`，再退回「已点节点的 branch 推算」。
  若显示「未分叉（0 个分支节点已点：技能点还不够深）」，是**真的还没点分支**（技能点只到 ROOT 层），不是数据没接。
- **技能精炼石**：「获得」按 `skillOrbGain` 事件求和（无事件时用余额增量兜底）；「已用」= 精炼花费 + 重置花费。
- `--json out/report.json` 里的 `report.skills` / `report.stomp` 含全部明细（`orbs` / `levels` / `forks` / `ranks` / `casts` / `modules`）。

### 旋风斩（whirlwind）

按住 **W（2 号技能键）**、**2 键** 或 **鼠标右键** 持续旋转（每秒消耗 6 点法力，移速 -25%），每 0.18 秒对周围 2.4 范围造成伤害。
视觉是两片绕角色旋转的金色刀光瓣 + 少量火星，跟随攻速与 AOE 天赋自动变快变大。

![旋风斩](docs/screenshots/whirlwind.png)

> 实现注意（踩过的坑）：旋风**不要**用细弧/圆环描边来画 —— 在 bloom 后处理下会被连成一圈刺眼的白环，

## 架构要点

- **逻辑与渲染彻底分离**：`src/core`、`src/items`、`src/game` 全部是纯逻辑（无 DOM / 无 Canvas），可以在 Node 里以 500 倍速跑完整局游戏——这也是自动化跑测与平衡调优的基础。
- **固定步长**：逻辑固定 1/60 秒，渲染插值；渲染层异常会自动降级为简易渲染而不影响游戏逻辑。
- **确定性随机**：所有随机都走 `RNG` 种子流，同种子地图/怪物/掉落完全一致（便于复现 bug 与测试）。
