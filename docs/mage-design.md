# 元素法师 · 职业设计案（实现版）

> 定位：**半自动元素循环**。玩家负责走位、锁定目标与终极技时机；技能循环由优先级引擎自动完成。
> 本文与 `src/core/mage.js` 的常量一一对应，改数值时请同步这里。

## 1. 职业定位

| 项目 | 战士 | 元素法师 |
| --- | --- | --- |
| 操作 | 全手动：左键普攻 + QWERT + 走位 | 半自动：走位 + 左键锁定 + T 大招 |
| 1 级生命 / 法力 | 120 / 60 | 88 / 100 |
| 1 级伤害 | 12–22 | 10–17 |
| 输出方式 | 近战扇形、旋风斩、控制 | 远程元素弹、AOE、印记反应 |
| 生存 | 护甲、格挡、生命偷取 | 冰霜屏障护盾、霜环眩晕、射程优势 |

法师的伤害基数仍取 `stats.dmgMin/dmgMax`，因此武器、装备与全局伤害词缀都能正常成长；
每点技能等级提供 **+12%** 伤害，与战士技能一致。

## 2. 技能栏（Q / W / E / R / T）

| 键 | 技能 | 法力 | 冷却 | 作用 |
| --- | --- | --- | --- | --- |
| Q | **灼热飞弹** | 4 | 1.1s | 单体火焰，叠 1 层火印记 |
| W | **寒冰箭** | 4 | 1.1s | 单体冰霜，叠 1 层冰印记 |
| E | **电弧** | 3 | 1.0s | 单体闪电，叠 1 层雷印记 |
| R | **炎爆术** | 18 | 7.5s | 目标半径 3 的火焰 AOE；3 层火时强化 |
| T | **元素狂潮** | 0 | 9s | 共鸣 100 时开启，8 秒爆发窗口 |

- **左键**：锁定目标（点到敌人锁定，点空地解除；锁定优先于自动选目标）。
- **空格**：闪现，沿用原 dash 的 0.18 秒无敌。
- 前四个技能既可以手动按，也由自动循环释放；自动与手动走同一条 `tryCast` 链路（法力、冷却、施法锁一致）。

## 3. 自动循环

### 3.1 节奏

- 每 **0.1 秒**评估一次优先级。
- 两次自动施法之间至少 **0.75 秒**（GCD），移动不打断循环。
- 目标选择：手动锁定（15 内有效）→ 当前目标（14 内粘住）→ 12 内最近敌人。
  粘住目标是为了避免「最近目标」每帧切换导致伤害被稀释。

### 3.2 优先级

1. **冰霜屏障**：生命 < 45%，且屏障冷却结束、法力 ≥ 6。
2. **霜环**：自身 4.2 范围内 ≥ 2 个敌人，冷却结束、法力 ≥ 12。
3. **强化炎爆**：目标 3 层火印记，且炎爆可用。
4. **雷链**：目标 ≥ 2 层雷，周围 4.0 内 ≥ 2 个敌人，冷却结束、法力 ≥ 16。
5. **多目标炎爆**：目标 ≥ 2 层火，周围 ≥ 3 个敌人。
6. **填充技**：按当前预设选择火 / 冰 / 雷中可用的一发。

### 3.3 三套预设

| 预设 | 选元素规则 | 适合 |
| --- | --- | --- |
| **均衡** | 火 → 冰 → 雷轮转 | 通用，先铺不同印记 |
| **反应流** | 优先选择能触发目标已有印记的元素 | 单体 / 快速刷反应 |
| **蓄积流** | 优先把同系印记叠到 3 层 | 打强化炎爆 / 霜环 / 雷链 |

预设只影响填充技与优先级偏置，不会让循环停摆；法力不足时自动跳过不可用技能。

## 4. 印记与元素反应

- 每次元素命中给目标叠 **1 层对应印记**，每种最多 **3 层**。
- 命中时若目标已有其它元素印记，消耗对方 1 层并触发反应。
- **每个目标 2.5 秒反应内置冷却**，防止高频触发导致特效与数值刷屏。
- 每次反应获得 **+15 共鸣**。

| 组合 | 反应 | 效果 |
| --- | --- | --- |
| 火 + 冰 | **熔解** | 追加火焰伤害（约 1.4 × 最低伤害基数） |
| 火 + 雷 | **超载** | 目标周围 2.6 范围爆炸，主目标全额、其它 70% |
| 冰 + 雷 | **等离子** | 雷电伤害 + 0.8 秒眩晕 |

### 3 层强化

| 技能 | 条件 | 强化 |
| --- | --- | --- |
| 炎爆术 | 目标 3 层火 | 伤害 ×1.9、半径扩大、眩晕 1 秒、**+25 共鸣** |
| 霜环 | 范围内任一目标 3 层冰 | 伤害与半径 ×1.45、眩晕 1.1 秒、**+25 共鸣** |
| 雷链 | 主目标 3 层雷 | 跳跃 5 次（普通 3 次）、**+25 共鸣** |

> 强化会消耗对应印记。炎爆的共鸣在目标被击杀时也照常结算，避免「补刀反而亏资源」。

## 5. 元素狂潮（T）

- 条件：**共鸣 100**，且当前不在元素狂潮中。
- 开启：清空共鸣，进入 **8 秒**强化：
  - 技能冷却 **减半**；
  - 施法 **退还法力**；
  - 每次命中附带 **2.2 范围、45% 伤害**的元素爆炸；
  - 结束时以自身为圆心 **4.6 范围**爆发（1.6 倍火焰伤害）。
- 开启后 T 进入 **9 秒冷却**，防止重复触发。
- 共鸣来源：元素反应 +15、3 层强化技能 +25。普通命中不产生共鸣，鼓励做反应与叠层，而不是无脑连发。

## 6. 自动专属技能

以下技能不占技能栏，避免与 5 格键位契约冲突：

| 技能 | 触发 | 冷却 | 效果 |
| --- | --- | --- | --- |
| **冰霜屏障** | 生命 < 45% | 22s | 获得 35% 最大生命的护盾，持续 6 秒 |
| **霜环** | 自身 4.2 内 ≥2 敌人 | 12s | 冰霜 AOE + 0.7 秒眩晕（强化 1.1 秒） |
| **雷链** | 目标 ≥2 层雷且周围 ≥2 敌人 | 9s | 在 5 范围内跳跃 3~5 次 |

## 7. 成长：法师专属天赋树

法师有**自己的 37 节点天赋树**（`src/items/mageTalentTree.js`），按 **P** 打开。
它与战士的 127 节点树完全独立：战士树保留原样，法师在 `talentTreeFor('mage')` 下读取自己的树，
加点 / 退点 / 重置 / 存档全部走同一套 `doTakeTalent` / `doRefundTalent` 接口。

### 7.1 结构

```
                    m-ks-storm（雷神之怒）
                           │
                      m-storm-cap
                     ╱           ╲
              m-storm-armL   m-storm-armR
                     ╲           ╱
                      m-storm-stem2
                           │
                      m-storm-stem1
                           │
                       m-storm-hub
                           │
                      m-storm-trunc
                           │
  中心 mage-start「元素之心」── 四条主干各 90°（烈焰 / 霜寒 / 雷霆 / 共鸣），
                           │     每条 7 个常规节点 + 1 个基石，内圈另有 4 个传奇。
                      m-fire-trunc …
```

- **37 个节点**：1 起点 + 4 主干 ×（7 常规 + 1 基石）+ 4 传奇。
- 四条主干：**烈焰**（火伤 / 范围 / 陨星）、**霜寒**（冰伤 / 控制 / 护盾）、
  **雷霆**（雷伤 / 连锁 / 冷却）、**共鸣**（共鸣 / 狂潮 / 自动循环）。
- 内圈传奇（`m-lg-*`）挂在相邻两条主干之间，早期就能绕到：
  **环形法球 / 三相归一 / 元素回响 / 共鸣核心**。
- 基石有明确取舍，例如「天火降世」+30% 火伤与陨星强化，但冰 / 雷伤害 -12%。

### 7.2 天赋如何影响战斗（全部可视）

| 天赋 | 机制 | 画面表现 |
| --- | --- | --- |
| **天火陨星**（烈焰 cap / keystone） | 每 9 秒（等级越高越快）轰击当前目标，范围火伤 + 短晕 | 天空斜落的火柱、落地裂纹、火焰圆盘与震屏 |
| **环形法球**（传奇） | 每 2.5 秒自动向最近敌人发射火 / 冰 / 雷弹 | 三色法球绕玩家旋转，弹道 + 命中火花 |
| **三相归一**（传奇） | 每 3 次填充施法，额外释放另外两系（50% 伤害） | 火 / 冰 / 雷三道弹道同帧命中 |
| **元素回响**（传奇 / 雷神之怒） | 元素反应向周围 3.2 范围弹射 | 从目标射向附近敌人的同色电光 |
| **三相共鸣**（共鸣 stem2） | 印记上限 3 → 4 | 怪物头顶的印记菱形最多 4 颗 |
| **霜环专精 / 绝对零度** | 霜环半径、冷却、冻结时长 | 更大的冰环、更多冰晶与冻结时间 |
| **永动狂潮** | 狂潮持续 +4 秒、冷却 -30%，击杀延长 | 脚下三色旋转光斑持续更久 |
| **强化专精 / 元素领主** | 满层强化技与反应伤害提高 | 强化炎爆 / 霜环 / 雷链的爆发更亮更大 |

实现上，天赋节点除了标准 `StatBlock` 字段外，还带一组 `mage*` 自定义字段
（`mageMeteor` / `mageOrbs` / `mageTrinity` / `mageReactionEcho` / `mageMarkMax` …）。
它们不会被 `recalcStats` 当成角色属性，而是原样留在 `player.talentStats`，
由 `core/mage.js` 的 `mageTalentMods(player)` 读取。

### 7.3 其它成长

- **技能等级 / 精炼石**：法师 5 个技能都可精炼，每级 +12% 伤害。
- **装备**：武器伤害、元素伤害、范围、冷却缩减、暴击等词缀全部生效；
  烈焰主干的「附加火焰伤害」也会进入法术基础伤害。
- **存档**：旧法师存档（没有法师节点）读档时自动重置到「元素之心」，
  不会把点数误投到战士树；法师存档会完整保留自己的天赋节点。
